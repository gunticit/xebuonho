# Kế hoạch: Admin duyệt KYC + Upload MinIO + Gate chống bypass + Luồng tài xế doanh nghiệp

## Context

Review code compliance vừa làm phát hiện: endpoint duyệt KYC không có phân quyền (ai cũng tự duyệt được), KYC submit thất bại ngầm (`vehicle_plate` vs `license_plate` + catch-all fake success), gate tài xế dựa trên JWT không verify + fail-open, và chưa có upload giấy tờ thật. Bạn yêu cầu: (1) admin panel duyệt KYC, (2) upload S3/MinIO, (3) phương án gate tốt nhất, (4) luồng riêng tài xế doanh nghiệp. Admin panel = **Flutter in-app** (bạn đã chọn); tài xế DN = **`driver_kind` trong role `driver`** (khuyến nghị, không phá CHECK constraint).

Phương án gate đã chọn (câu 3): **chống bypass 3 tầng** — (T1) SQL atomic ở `AcceptRide` (nơi gán cuốc thật sự xảy ra hôm nay), (T2) handler check + sửa `resolveDriverID` + wrap auth `/api/v1/driver/`, (T3) matching-service lọc `approval_status` qua Redis `driver:{id}:meta`. Tất cả **fail-closed**.

## 1. Migration + seed (`migrations/000005_business_driver_and_admin.up/down.sql`)

- `users`: thêm `driver_kind VARCHAR(20) NOT NULL DEFAULT 'personal' CHECK IN ('personal','business')`; cột DN: `company_name`, `company_tax_code`, `business_license_number/_url`, `transport_license_number/_expiry DATE`, `employment_contract_url`, `blackbox_installed BOOL`, `cabin_camera_installed BOOL` (theo NĐ 10/2020 + 47/2022, phù hiệu/hộp đen/camera đã nêu trong `docs/KE_HOACH_THUONG_MAI_HOA.md:95-103`).
- Seed admin demo: `INSERT INTO users ... role='admin' ON CONFLICT (phone) DO NOTHING` (phone `0900000001`, password `admin123` — bcrypt hash sinh lúc code bằng `golang.org/x/crypto/bcrypt`; ghi chú đổi mật khẩu khi production).
- down: DROP cột + DELETE admin seed.
- `Makefile`: thêm `minio` vào `docker-up`; `migrate-up` chạy thêm dir top-level `migrations/` (hiện chỉ loop `services/*/migrations` đang rỗng, còn 000004 nằm ở top-level —修 luôn mismatch này).

## 2. MinIO upload (presigned PUT) — infra + user-service

- `deployments/docker-compose.dev.yml`: service `minio` (minio/minio, port 9000 API + 9001 console, volume `minio_data`, healthcheck) — theo style postgres/redis hiện có.
- `services/user-service`: thêm `minio-go/v7`; config `MINIO_ENDPOINT/ACCESS_KEY/SECRET_KEY/BUCKET/SECURE` theo pattern `getEnv` (`cmd/main.go:95-116`); init client + `EnsureBucket` lúc start; inject vào AuthService.
- Endpoint mới `POST /api/v1/auth/uploads/presign` (JWT bắt buộc): body `{doc_type, file_ext, content_type}` → trả `{object_key, upload_url}` presigned PUT TTL 15m. Whitelist content-type (jpeg/png/webp) + doc_type (cccd_front/back, gplx_front/back, vehicle_registration, vehicle_insurance, business_license, transport_license, employment_contract). Key: `kyc/{userID}/{doc_type}/{uuid}.{ext}`.
- KYC payload gửi `object_key` vào các cột `*_url` hiện có (không đổi schema); `GET /admin/drivers/{id}` trả về presigned GET URL 15m cho mỗi key để admin xem ảnh.
- Không proxy multipart qua backend (presigned chuẩn cho mobile; MinIO mặc định cho CORS với Flutter web).

## 3. user-service — admin API có phân quyền + KYC mở rộng

- `handler/auth_handler.go`: thêm `extractAuth(r) (userID, role)` (dùng `ValidateJWT` — hiện chỉ bỏ vai trò vào `_`) + `requireAdmin` → 403 nếu `role != "admin"`.
  - `AdminDriverApproval` (dòng 193): **bắt buộc requireAdmin**, ghi `approved_by = adminID` khi approved (audit trail — cột đã có từ 000004 nhưng chưa từng được ghi).
  - Mới: `GET /admin/drivers?status=&kind=` (list, dùng repo mới `ListDriversByStatus`) và `GET /admin/drivers/{id}` (detail + presigned doc URLs).
  - Mới: `PresignUpload`.
- `service/auth_service.go` `SubmitDriverKYC`: validate server-side CCCD đúng 12 số, parse ngày GPLX/bảo hiểm (sai format → lỗi rõ ràng); `driver_kind='business'` bắt buộc có company_name, business_license_number, transport_license_number, employment_contract_url.
- Khi đổi approval status: best-effort ghi `approval_status` vào Redis hash `driver:{id}:meta` (chuỗi với matching-service; log nếu Redis lỗi).

## 4. api-gateway — gate fail-closed 3 tầng

- `router/router.go:122`: wrap `mux.Handle("/api/v1/driver/", authMiddleware(driverH))` — hiện đang KHÔNG có auth (pattern cụ thể thắng catch-all).
- `handler/driver_handler.go`: `resolveDriverID` (48-68) chỉ dùng `middleware.GetUserID`, rỗng → 401; xoá decode-JWT-không-verify + UUID demo hardcode (cả ở dòng 171, 218). `ToggleStatus` + `AcceptRequest`: check approval qua `GetDriverApprovalStatus`, **err != nil → 403** (fail-closed).
- `repository/postgres_repo.go` `AcceptRide` (281-295): thêm vào WHERE `AND EXISTS (SELECT 1 FROM users u WHERE u.id=$2 AND u.role='driver' AND u.approval_status='approved' AND u.is_active=TRUE)` — gate atomic với claim cuốc. `GetDriverApprovalStatus` (549): trả lỗi thay vì fallback 'approved'.

## 5. matching-service — tầng T3 (nhỏ)

- `internal/model/driver.go` + `repository/geo_repo.go` `GetDriverMeta`: đọc thêm `approval_status`; `service/matching_service.go` `FindNearbyDrivers` (83-98): skip khi field **có mặt** và != 'approved' (missing meta → không chặn, tránh phá demo data hiện có).

- `pubspec.yaml`: thêm `image_picker`.
- `config/api_config.dart` + `services/api_service.dart`: `presignUpload()`, `uploadToMinio()` (Dio PUT bytes), sửa `submitDriverKYC` gửi đúng `license_plate`; admin methods `listDrivers/getDriverDetail/approveDriver`.

- Thứ tự luồng (fix P1): register driver (cả 2 kind) → `/otp` trước; `otp_screen.dart` (dòng 58/242) sau verify → nếu `auth.isDriver` → `/driver/kyc`, admin → `/admin`.
